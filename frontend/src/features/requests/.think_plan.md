# 请求详情与日志防护改造计划

## 范围

- 请求详情页标题、概览和对话阅览器 UI。
- 请求日志持久化失败与中转响应之间的隔离。

## 根因

- Request 详情查询未读取最新 RequestExecution 的 `responseStatusCode`，标题无法显示 HTTP 状态码。
- 对话阅览器的长文本、工具参数和推理展开状态分别由子组件持有，全局按钮只切换父级布尔值，既不能重置子组件状态，也没有传递到工具参数卡。
- 日志创建和渠道回写错误从持久化中间件返回，可能中断实际上游请求；日志属于旁路副作用，不应成为请求链路的失败条件。

## 实施约束

- 原始请求与响应 body 不截断、不重写；仅复制用于展示或持久化。
- 持久化失败只记录告警并继续返回原请求/响应。
- 状态码来自最新执行记录，缺失时保留状态标签，不伪造状态码。
- 不执行构建或 lint；通过静态差异检查和已有针对性测试验证。
